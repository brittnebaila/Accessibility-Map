# Accessibility Map

A responsive web app built with React and Leaflet that helps people evaluate how steep nearby streets are around a chosen address.

## MVP

- Enter an address
- Select a radius
- View nearby street segments on a map
- Color streets by estimated grade:
  - Green for easier streets
  - Yellow for moderate streets
  - Red for steep streets

## Goal

Make it easier for people with disabilities or difficulty walking to quickly understand the terrain around a destination before they go.
